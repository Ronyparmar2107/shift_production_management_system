## Shift Production Management System

A full-stack showcase project built to demonstrate production-grade patterns 
in React, ASP.NET Core, and MSSQL — modeled on a real industry problem: 
tracking shift production against plan in real time for underground and 
open-pit mining operations.

Rather than a generic CRUD demo, this project focuses on the kind of 
decisions a real ops team actually needs: role-based access with 
multi-role support, historical (never-overwritten) crew and role 
assignment tracking, live plan-vs-actual variance calculation, and a 
JWT-secured API with a properly layered service/DTO architecture.

**Stack:** React (Vite) · ASP.NET Core Web API · Entity Framework Core · 
MSSQL · JWT authentication
